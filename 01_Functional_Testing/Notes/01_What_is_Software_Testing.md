# What is Software Testing?

## Definition

Software Testing is the process of verifying and validating a software application to ensure it meets business requirements, works correctly, and is free from defects (bugs).

---

## Why is Software Testing Important?

Software testing is important because it helps:

- Find defects before software is released.
- Improve software quality.
- Ensure the application works as expected.
- Increase customer satisfaction.
- Reduce maintenance costs.
- Improve application security and performance.

---

## Objectives of Software Testing

- Verify that the application works correctly.
- Validate business requirements.
- Detect defects early.
- Improve software quality.
- Prevent production failures.
- Deliver a reliable product to users.

---

## Key Terms

### Verification

Verification checks whether the software is built according to the specified requirements.

**Question:** Are we building the product correctly?

---

### Validation

Validation checks whether the software satisfies the customer's needs.

**Question:** Are we building the right product?

---

### Defect (Bug)

A defect is a problem or error in the software that causes unexpected behavior.

Example:

- Login button does not work.
- Wrong total amount displayed.
- Application crashes after clicking Submit.

---

## Real-Time Example

### Application

Amazon Login Page

### Test Steps

1. Open the Amazon Login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click the **Login** button.

### Expected Result

The user should successfully log in and reach the Home page.

### Actual Result (Example Bug)

The Login button does not respond after clicking.

**Status:** Failed

## Interview Questions

Software Testing is the process of verifying and validating software to ensure it meets business requirements and is free from defects.

---

---

### Q3. What is a Defect?

## Summary

Software Testing is a quality assurance activity that verifies and validates software before it reaches customers. Its main goal is to detect defects, ensure business requirements are met, and deliver reliable, high-quality software.
